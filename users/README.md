但先打一个注释：
先是关于这个文件夹“类/home”的解释。传统的home目录在我看来有两个问题：一是用户目录会容纳缓存和很多稀奇古怪的应用的自建目录，会被“污染”，我不喜欢；二是在易失性配置下，对于home下内容的高颗粒度impermanence很麻烦。所以我就想与其去保存用户目录里这些东西，不如干脆啥都不要，我在用户账户登录的时候把内容全部链接/拷贝过去。对应过来就是HM的mkOutOfStoreSymlink，以用户为粒度划分需要读取的dotfiles
然后就是HM的常规功能也在这里定义，像什么用户软件、用户服务......
