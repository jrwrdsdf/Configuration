很显然这里是用来放指定主机的配置的
我现在计划是把每台机器的基本配置分成system.nix、hardware.nix两个主要和其他如specilation1.nix（如果需要配置多实例）、impermanence.nix（如果配置易失性）这样的外周配置。好处是各个机器都可以得到最适合自己体质的配置，坏处是配置的可复用性会比较差，但我觉得能接受，因为我暂时想不到有什么配置是需要复用的PwP
hardware.nix里面配置基本的文件系统、CPU、NPU、GPU驱动（以及多显卡间的协作模式）和ZRAM/Zswap这些基础的东西
system.nix则开始定义那些UNIX用户空间的东西——用户定义、系统服务（强调一下，这里是指我希望以系统服务运行的服务，而不是常规认识的系统服务。就比如Pipewire，我不仅希望它以用户服务运行，连带着它的定义我都想塞进HM里）
